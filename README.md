# K-MAJOR BASEBALL ⚾🔥

MLB의 볼파크 감성과 KBO의 응원 문화를 섞은 **3D 툰 셰이딩 야구 게임**입니다.
Three.js로 만들었으며, 외부 에셋 없이 모든 캐릭터/경기장/사운드를 코드로 생성합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 정적 빌드
```

## 특징

- **툰 셰이딩**: 밴드형 그라디언트 램프 + 림 라이트 + 쿨톤 그림자 + 인버티드 헐 외곽선(스킨드 메시 지원), 블룸/비네트/색수차 포스트 프로세싱
- **길쭉한 비율의 캐릭터**: 절차적 스킨드 메시(관절 블렌딩 스키닝), 손가락 뼈까지 있는 손, 캡/헬멧/글러브/포수 마스크
- **매끄러운 애니메이션**: Catmull-Rom 키프레임 보간 + 쿼터니언 크로스페이드 + 2본 IK(배트 양손 그립, 글러브 캐치, 투구/송구 팔 궤적)
- **경기장**: 잔디 체커 패턴, 흙 내야, 워닝트랙, 광고 펜스, 폴대, 관중석 볼(bowl), 1만 명 이상의 인스턴싱 관중(막대풍선 응원), 응원단 무대, 전광판, 조명탑, 노을 하늘, 도시 스카이라인
- **야구 기술**
  - 투구: 포심·싱커·커터·슬라이더·스위퍼·커브·체인지업·포크·너클 (타이밍 게이지로 제구)
  - 타격: 일반/파워/컨택 스윙, 번트(희생번트), PCI 커서 + 타이밍 기반 타구 물리(당겨치기/밀어치기, 발사각)
  - 주루: 도루, 리드, 슬라이딩(발/헤드퍼스트), 태그업, 추가 진루 판단, 포스/태그 아웃
  - 수비: 자동 수비 AI — 타구 예측·추적, 다이빙 캐치, 펜스 점프 캐치(홈런 강탈), 커버 플레이, 병살, 중계 송구, 견제
  - 규칙: 볼카운트, 볼넷/사구, 삼진, 파울/페어 판정, 인정 2루타, 희생플라이, 3아웃 포스 시 득점 무효, 끝내기, 연장
- **필살기 (화려한 이펙트)**: 게이지가 차면 사용
  - 🔥 **블레이즈 라이징** (Q) — 172km/h 화염 라이징 패스트볼
  - 👻 **팬텀 포크** (W) — 분신이 갈라지며 사라지는 마구
  - ⚡ **뇌신 스위퍼** (R) — 번개와 함께 휘어지는 스위퍼
  - 🐉 **드래곤 드라이브** (E) — 황금 오라 + 초대형 홈런 스윙
  - ✨ **섬광 일섬** (T) — 갭을 가르는 라이너
  - 🌪️ **질풍 도루** (G) — 바람을 두른 절대 도루
  - 컷인 연출, 슬로모션, 히트스톱, 충격파, 번개, 불꽃놀이, 방사형 블러, 화면 흔들림

## 조작

| 상황 | 조작 |
| --- | --- |
| 타격 | 마우스/방향키로 커서 이동, 클릭·Space 스윙, Shift+스윙 파워, C 컨택, B 번트, S 도루, E/T/G 필살기 |
